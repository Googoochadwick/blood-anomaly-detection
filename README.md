# Blood Anomaly Detection

🩸 Blood Anomaly Detection is a Streamlit-based exploratory app and demo that classifies blood cell samples as "Normal" or "Anomaly" using several pre-trained models (Decision Tree and XGBoost). It includes both full-feature and reduced-feature interfaces, example visualizations, and the dataset used for the demo.

## Key features
- Interactive Streamlit UI for exploring the dataset and making predictions.
- Four pre-trained models included:
  - Decision Tree (full / minimal features)
  - XGBoost (full / minimal features)
- Visualizations for correlation and feature importance.
- Dataset bundle (Kaggle) included for quick experimentation.

## Stack
- Language: Python 3.14.7
- Runtime / framework: Streamlit
- Notable libraries: pandas, numpy, scikit-learn, xgboost, joblib, seaborn, matplotlib
